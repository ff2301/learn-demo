# learn-demo

A Vite + React workspace for collecting small learning demos.

## Scripts

- `pnpm dev` starts the local Vite dev server.
- `pnpm routes:generate` regenerates the TanStack Router route tree.
- `pnpm typecheck` regenerates routes and runs TypeScript.
- `pnpm lint` runs Biome checks.
- `pnpm knip` checks for unused files, exports, and dependencies.
- `pnpm check` runs `typecheck`, `lint`, and `knip`.
- `pnpm build` typechecks and builds the production bundle.
